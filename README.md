# OverTheWire: Bandit Challenge

This repository contains my solutions and notes for the [OverTheWire Bandit Challenge](https://overthewire.org/wargames/bandit/).

## Objective
The Bandit wargame is designed for beginners to learn the basics of the Linux command line. Each level requires finding a password hidden in various ways to log into the next level via SSH.

## What I Learned
Completing these challenges significantly improved my command-line skills. Specifically, this project helped me:
* Navigate and manipulate the Linux file system with ease.
* Understand file permissions, hidden files, and piping commands.
* Greatly enhance my overall workflow efficiency by relying on the terminal rather than a graphical interface.
